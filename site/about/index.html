About

The T.O. Mayoral Files is an independent civic-transparency project documenting Toronto's 2026 mayoral race. Not affiliated with any candidate, campaign, or political party. No financial relationship with any candidate.

Every record on this site is sourced to a specific public Instagram post. Click any source link to verify against the original.

Built by BottleneckLabs. Open source at GitHub under the MIT license.
